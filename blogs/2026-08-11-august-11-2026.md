Cloud SQL for MySQL Feature The Cloud SQL remote MCP server now supports specialized endpoint URLs (toolsets) for /readonly , /instance_manage , and /query_execution . Specialized toolset URLs let you restrict the set of exposed MCP tools based on your security and workflow requirements. For more information, see Available toolsets .
