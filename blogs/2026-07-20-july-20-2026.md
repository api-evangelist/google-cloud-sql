Cloud SQL for MySQL Feature Cloud SQL for MySQL now supports authentication via Secret Manager when executing SQL statements using the Data API ( executeSql ). You can store your database password in a regional secret in Secret Manager and pass the secret version resource name in your API request. For more information, see Execute SQL statements on a Cloud SQL instance .
