Cloud SQL for MySQL Issue When you enable the Knowledge Catalog (formerly Dataplex Universal Catalog) integration on a Cloud SQL for MySQL instance created before April 18, 2026, the integration defaults to once a day instead of near real-time. Near real-time updates upon Knowledge Catalog enablement aren't yet available for all existing instances. A new announcement will be published when this feature becomes available.
