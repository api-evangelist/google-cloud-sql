Cloud SQL for MySQL Feature Performance capture for Cloud SQL for MySQL is now generally available ( GA ). Performance capture lets you take a point-in-time snapshot of your database and operating system metrics automatically and route them to Cloud Logging for root-cause analysis. With the GA release, you can configure custom thresholds that end long-running transactions automatically before they slow down your database.
