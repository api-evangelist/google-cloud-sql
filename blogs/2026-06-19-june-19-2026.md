Cloud SQL for MySQL Change When you migrate from Percona XtraBackup physical file to Cloud SQL for MySQL , you can now specify multiple data files in the innodb_data_file_path parameter of your external server configuration. Also, you are no longer required to use the default name for your data files. Change Cloud SQL for MySQL now supports multiple system tablespace files, allowing system tablespace size to grow larger than 16TB.
