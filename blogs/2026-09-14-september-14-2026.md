Cloud SQL for PostgreSQL Feature You can use the pg_textsearch extension in Cloud SQL for PostgreSQL to perform full-text search using the industry-standard BM25 (Best Matching 25) scoring algorithm for highly accurate relevance scoring. This extension requires PostgreSQL 17 or later and is supported on PostgreSQL release R20260712.01_06 or later. For more information, see Full-text search using pg_textsearch .
