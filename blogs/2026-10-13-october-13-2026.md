Cloud SQL for MySQL Feature Private Service Connect is now the default private IP connectivity option when you create a Cloud SQL for MySQL instance in a new Google Cloud project. Private Service Connect lets you connect to your instance from multiple Virtual Private Cloud (VPC) networks across different groups, projects, or organizations, and supports automatic endpoint and DNS record provisioning. When you configure private IP for an instance, you can still choose to use private services access or both connectivity options.
