Cloud SQL for PostgreSQL Feature Database Migration Service quick-start migrations are now integrated into Cloud SQL for PostgreSQL to provide a lightweight, continuous migration flow. This feature automates setup for sources with private IPs in a VPC network, including Cloud SQL for PostgreSQL instances and self-managed databases on Compute Engine. For more information, see Quick-start migrations overview in the Database Migration Service documentation. This feature is in Preview .
