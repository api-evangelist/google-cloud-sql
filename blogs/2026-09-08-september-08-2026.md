Cloud SQL for MySQL Feature Regional endpoints (REP) are now generally available ( GA ) for the Cloud SQL for MySQL Admin API. Regional endpoints let you interact with Cloud SQL for MySQL instances using regionalized URLs (such as sqladmin. {region} .rep.googleapis.com ) rather than through a single global endpoint.
