Cloud SQL for MySQL Feature Cloud SQL for MySQL now supports the innodb_cloudsql_managed_buffer_pool_tuneup_pct database flag. Managed buffer pool automatically adjusts the InnoDB buffer pool size to reduce out-of-memory events. When instance memory usage remains at or below 70% for 10 minutes or longer after prior reductions, Cloud SQL increases the buffer pool size.
