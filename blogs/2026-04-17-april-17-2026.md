Cloud SQL for SQL Server Feature You can now integrate Cloud SQL for SQL Server with Vertex AI and third-party models ( Preview ). By integrating your Cloud SQL for SQL Server instance with Vertex AI, you can generate vector embeddings from models hosted in Vertex AI directly from your Cloud SQL instance. Cloud SQL for SQL Server supports model endpoints from the following sources: Vertex AI Hugging Face OpenAI For more information, see Integrate Cloud SQL for SQL Server with Vertex AI .
