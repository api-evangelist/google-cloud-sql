Cloud SQL for MySQL Feature Cloud SQL for MySQL managed buffer pool is now generally available ( GA ). Managed buffer pool helps you avoid out-of-memory events (OOMs) on your Cloud SQL instance by reducing innodb_buffer_pool_size when memory usage is high.
